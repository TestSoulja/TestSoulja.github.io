Imagine we want to scrape a platform containing publicly available real estate listings. We want to get the property price, its address, distance, station name and the nearest transport type so we can learn how property prices are distributed depending on public transport accessibility in a particular city.

Suppose the request leads to a results page that looks like this: Search results for scraping in Python Once we know which elements of the site store the required data, we need to design scraping logic that will let us get all the necessary information from each listing. We need to answer the following questions:

  • How do we get a single data point for a single property (for example, data from the price tag in the first listing)?
  • How do we get all data points for a single property from the whole page (for example, all price tags on one page)?
  • How do we get all data points for a single property from all results pages (for example, all price tags from all results pages)?
  • How do we handle the mismatch when data can be of different types (for example, some listings specify “price on request” in the price field. In the end we will have a column consisting of numeric and string values, which in our case prevents analysis)?
  • What is the best way to extract complex information (for example, suppose each listing contains public transport information such as “0.5 miles to metro station XY”)?
