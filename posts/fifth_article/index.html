How Flask handles requests

How does Flask know which function to output when it receives a request from a client?

Flask matches URLs with the view functions that will be output. The mapping (routing) is created using the route decorator or the add_url_rule() method on a Flask instance. These mappings can be accessed through the url_map attribute of the Flask instance.

>>>
>>> from main2 import app
>>> app.url_map
Map([<Rule '/' (OPTIONS, GET, HEAD) -> index>,
 <Rule '/static/<filename>' (OPTIONS, GET, HEAD) ->  static>,
 <Rule '/books/<genre>' (OPTIONS, GET, HEAD) ->  books>,
 <Rule '/user/<user_id>' (OPTIONS, GET, HEAD) ->  user_profile>])
>>>

As you can see, there are 4 rules. Flask defines URL matches in the following format:

url pattern, (comma separated list of HTTP methods handled by the route) -> view function to execute

The path /static/<filename> is added automatically for Flask static files. Working with static files is covered in a separate lesson, “Serving static files in Flask”.
