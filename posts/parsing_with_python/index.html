Parsing with Python

  • Category: Python
  • Project: Python course for beginners
  • Published: 2022-06-10
  • Platform: Python Workshop
import matplotlib.pyplot  as plt

The following grammar applies here: first comes the import keyword, then the module name or a chain of module names separated by dots, then the as keyword, followed by our name for the imported module.

As a result of parsing, for example, we may need to arrive at the following expression:

{ 'import': [ 'matplotlib', 'pyplot' ], 'as': 'plt' }

This expression is a Python dictionary with two keys: 'import' and 'as'. The value for the 'import' key is a list that enumerates the names of the imported modules in order.

Regular expressions are usually used for parsing. Python has a module called re (regular expression) for this. If you have never worked with regular expressions, their appearance may scare you. For example, for the code string 'import matplotlib.pyplot as plt' it will look like this:

r'^[ \t]*import +\D+\.\D+ +as \D+'
