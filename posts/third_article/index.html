Flask from scratch

  • Category: Flask
  • Project: Flask course for beginners
  • Published: 2022-06-14
  • Platform: Flask Workshop

You can start getting acquainted with Flask by creating a simple application that outputs “Hello World”. Create a new file main.py and enter the following code.

from flask import Flask

app = Flask(__name__)

@app.route('/')
def index():
    return 'Hello World'

if __name__ == "__main__":
    app.run()

This is the “Hello World” application built with the Flask framework. To run main.py, execute the following command:

(env) python main.py
Running on http://127.0.0.1:5000/ (Press CTRL+C to quit)
