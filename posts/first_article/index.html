Getting started with Flask

  • Category: Flask
  • Project: Flask course for beginners
  • Published: 2022-06-12
  • Platform: Flask Workshop
from flask import Flask

app = Flask(__name__)

On the first line, the Flask class is imported from the flask package.

On the second line, a Flask object is created. To do this, the name argument is passed to the Flask constructor. The Flask constructor must have one required argument — the name of the package. In most cases the value of name is suitable. The application package name is used by Flask to find static files, templates, etc.

Creating routes

A route is used in Flask to bind a URL to a view function. This function handles the request. In Flask, the route decorator is used to associate a URL with a function. Here is how a route is created.

@app.route('/')
def index():
    return 'Hello World'

This code makes the index() function the handler for the root URL of the application. In other words, every time the application receives a request whose path is /, the index() function is called and the request is completed there.
